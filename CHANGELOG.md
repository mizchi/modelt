# Changelog

## 0.1.0-alpha.0

- Share typed values, observation-bearing finite models, conformance checking and trace replay between TypeScript and Rust native/Wasm.
- Add failure-preserving shrinking and deterministic host boundaries for clock, message delivery, choices and durable storage.
- Evaluate an archived async-mutex bug against its actual fixed revision and retain reproducible evidence.
- Include the Wasm core and CLI in the npm archive, make solver adapters optional, and verify standalone npm/Cargo consumers.
- Consolidate PR verification into one runner; retain explicit heavy runtime and cloud shard workflows.

Experimental release. Model-language callbacks, liveness/fairness, automatic OS instrumentation and Go bindings are outside the supported scope.
